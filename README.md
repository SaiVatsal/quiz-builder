# QuizVortex — Synchronous Multiplayer Quiz Builder & Game Arena

An interactive, game-show styled quiz creation and live multiplayer platform built with React 18, Vite 5, Tailwind CSS, and Zustand.

## Features
- **Arena Library**: Explore curated quiz decks across Science, Distributed Systems, Gaming Lore, and Trivia with difficulty badges and play counts.
- **Synchronous Live Game Mode**: Host live multiplayer sessions with unique game room PINs, animated avatars, and live participant lists.
- **Fast-Paced Answering Mechanics**: Big chunky geometric answer blocks (Kahoot/Quizizz style) with speed bonus multipliers, streak counters, and countdown clocks.
- **Live Dynamic Leaderboard**: Real-time podium standings with animated position tracking and streak tags.
- **Creator Studio**: Author multi-choice, true/false, and open-ended questions with custom time limits (10s to 30s) and points allocations.
- **Creator Telemetry & Analytics**: Detailed question-by-question accuracy curves, average response times, and dropout metrics.

## Running Locally
```bash
npm install
npm run dev
```
Port: `http://localhost:3038`
